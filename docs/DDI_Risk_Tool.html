Basic models

Reversible inhibition — FDA 2020 Fig. 1 / ICH M12 §2.1.2.1
R1 = 1 + (Cmax,u / Ki,u)    trigger R1 ≥ 1.02 (i.e. Cmax,u/Ki,u ≥ 0.02)
R1,gut = 1 + (Igut / Ki,u), Igut = Dose / 250 mL    trigger R1,gut ≥ 11 (CYP3A, oral)
Ki,u = Ki × fu,mic; Ki = IC50/2 when [S] ≈ Km
Time-dependent inhibition — FDA 2020 Fig. 2 / ICH M12 §2.1.2.2
R2 = (kobs + kdeg) / kdeg    trigger R2 ≥ 1.25
kobs = kinact × m·Cmax,u / (KI,u + m·Cmax,u)
  m = 50 (FDA 2020) or m = 5 (ICH M12) — this is a real difference between the two documents
Mechanistic static model — FDA 2020 Fig. 7 / ICH M12 Table 3 (Fahmi 2009)
AUCR = 1/[(Ag·Bg·Cg)·(1−Fg) + Fg] × 1/[(Ah·Bh·Ch)·fm + (1−fm)]
A = 1 / (1 + [I]/Ki)
B = kdeg / (kdeg + [I]·kinact/([I] + KI))
C = 1 + d·Emax·[I]/([I] + EC50)  (= 1 here: inhibition-only assessment)
[I]h = fu,p × (Cmax + Fa·Fg·ka·Dose / Qh / RB)
[I]g = Fa·ka·Dose / Qen
Hepatic inlet (for OATP1B1/3) — FDA 2020 Fig. 6
Iin,max = Cmax + (Fa·Fg·ka·Dose)/Qh/RB
R = 1 + (fu,p·Iin,max / IC50)    trigger R ≥ 1.1

The fu,p < 1% rule

Both FDA 2020 and ICH M12 state that where fu,p is experimentally determined to be < 0.01, a value of 0.01 must be used in these calculations. This tool applies that floor automatically and tells you when it has done so. It can be switched off in Cut-offs & constants for an internal sensitivity analysis, but the regulatory submission number is the floored one.

These are basic and static models. They are deliberately conservative and generate false positives. A basic-model trigger means "cannot be excluded in vitro", not "there will be a DDI" — the next step is a mechanistic static or PBPK assessment, or a clinical study with a sensitive index substrate.
